# Codebase Atlas

This is the navigation system for the repository. It is meant to answer “where should I look?” before anyone opens a large class and reads line by line.

## How To Use This Atlas

- Start with the architecture page if you need the big picture.
- Use the task guide if you already know the kind of change you want to make.
- Use the generated indexes when you need a complete file/package map.
- Use the source-folder READMEs when you are already inside a code area and want local context.
